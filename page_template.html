What it takes to turn 100 apps into agent toolkits

An agent researched auth, access gating, API surface, MCP status and buildability for each app, then a second agent pass and a hand-checked sample tested its accuracy.

Patterns

Findings

The agent

1. Search3 queries per app: auth docs, access and pricing, MCP.
2. ExtractGemini reads only the retrieved sources and returns fixed-schema JSON.
3. ClampCode drops any evidence URL that was not in the sources and downgrades confidence.
4. VerifyA skeptical second pass reloads the cited pages (HTTP, then headless browser) plus fresh search.
5. HumanHand-built gold set for 20 apps, checked against official docs.

Verification

Accuracy against the hand-checked sample, first pass versus after the verification loop. Misses are listed, not hidden.
